# cs_learning_resources

A collection of links / references for CS

## Linux & the shell

- The Linux Command Line — William Shotts [Linux command](https://linuxcommand.org/tlcl.php)

The canonical beginner-to-intermediate guide. 
Covers filesystem, processes, permissions, scripting. ~500 pages but readable in sections.

- [Linux Journey](https://linuxjourney.com)

Bite-sized lessons with exercises. Good for the first pass before Shotts.

## Git + Conventional Commits
- [Pro Git](https://git-scm.com/book/en/v2)

The official reference. 
Chapters 1–3 cover 90% of daily work; 
Chapter 5 (distributed workflows) and 7 (tools) are worth reading.

- [Learn Git Branching](https://learngitbranching.js.org)

Visual, gamified rebase/merge/cherry-pick practice. The team rebases and uses SemVer tags — this builds muscle memory.

- [Conventional Commits](https://conventionalcommits.org)
